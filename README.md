# KHARGO CONSTRUCTIONS

A responsive React website for KHARGO CONSTRUCTIONS, a real estate builders and construction company serving Bongaigaon, Assam.

## Run locally

```sh
npm install
npm run dev
```

Create a production build with `npm run build` and preview it with `npm run preview`.

## Project notes

- Routes: `/`, `/about`, `/services`, `/projects`, `/packages`, `/contact`, and `/faq`.
- Indicative demo rates are maintained in `src/data/packages.js`.
- Business details and verified service categories are maintained in `src/data/site.js`.
- Generated service images are illustrative. Project gallery items are labelled representative demo imagery.
- The contact form prepares an enquiry in WhatsApp; the website does not store or send the form data.
